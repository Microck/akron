title: Global
description: Session-wide controls for speed, safety, submission metadata, autosave, and transition behavior.
---

The Global tab contains session-wide options.

| Option | Control | What it does | Classification |
|---|---|---|---|
| Timescale | Numeric input | Enable a configured gameplay timescale and edit its multiplier independently. | Cheat |
| Transition Speed | Toggle | Adjust the next room-transition speed multiplier. Values below 1x are slower and values above 1x are faster. | Cheat |
| Frame Stepper | Toggle | Enable frame stepping while Freeze Gameplay is on and configure hold-to-repeat stepping. | Cheat |
| FPS Bypass | Numeric input | Raise the draw cadence or enable Motion Smoothing's smoothing pipeline while keeping Celeste physics at 60 TPS when TPS Bypass is off. | Normal clear |
| TPS Bypass | Numeric input | Change the simulation tick cadence. | Cheat |
| Safe Mode | Toggle | Safe Mode indicator plus optional local stat guards for deaths, jumps, and best-run fields. | None |
| Freeze Attempts | Toggle | Restore the current save slot's death counter while Safe Mode is active. | Cheat |
| Submission Mode | Toggle | Enable recording metadata defaults and related warning surfaces without changing gameplay itself. | Goldberry/Hardlist clear |
| Pause Buffering | Toggle | Choose whether configured hotkeys can fire while Celeste is paused. | Cheat |
| Autosave | Toggle | Save the active Celeste file automatically at configured triggers, with optional settings saves. | Goldberry/Hardlist clear |
| Defer Engine GC | Toggle | Move Celeste's forced blocking garbage collection off death and room reload and onto the next StartPos load. On by default. | Normal clear |

<Note>
  FPS Bypass and TPS Bypass appear only when Motion Smoothing is loaded. FPS Bypass changes drawing while Celeste physics stays at 60 TPS when TPS Bypass is off. TPS Bypass changes the physics cadence.
</Note>

## Option menus

Rows with a triangle expose the controls listed below.

| Option | Menu control | What it changes | Classification |
|---|---|---|---|
| FPS Bypass | Target FPS | Draw target while FPS Bypass is enabled. When TPS Bypass is off, Motion Smoothing keeps Celeste physics at 60 TPS while drawing extra frames. | Normal clear |
| FPS Bypass | Method | Interval keeps render cadence aligned to physics ticks. Dynamic allows arbitrary FPS but is riskier for code that hooks the main tick. | Normal clear |
| FPS Bypass | Smooth Camera | Fancy is highest quality, Fast is cheaper but can jitter backgrounds, Off leaves the camera pixel-locked. | Normal clear |
| FPS Bypass | Objects | Extrapolate predicts between physics frames. Interpolate uses prior frames and can add 1-2 frames of delay. | Normal clear for Extrapolate; Cheat for Interpolate |
| FPS Bypass | TAS mode | Keeps overworld updates locked for TAS compatibility while level gameplay remains controlled by TPS Bypass. | Cheat |
| FPS Bypass | Subpixel Madeline | Reference option for drawing Madeline and held items at subpixel render positions. | Normal clear |
| FPS Bypass | Smooth background | Reference option for high-resolution background compositing in Fancy camera smoothing. | Normal clear |
| FPS Bypass | Smooth foreground | Reference option for high-resolution foreground compositing in Fancy camera smoothing. | Normal clear |
| FPS Bypass | Hide edge gaps | Reference option: slightly zooms the level to hide gaps introduced by fractional camera offsets. | Normal clear |
| FPS Bypass | Nasty mode | Apply the experimental smoothing preset that Motion Smoothing recommends avoiding in real gameplay. | Cheat |
| Frame Stepper | Step once | Advance one frozen frame. Only works while Frame Stepper and Freeze Gameplay are on. | Cheat |
| Frame Stepper | Hold key repeats | When enabled, holding the step key advances frames repeatedly. | Cheat |
| Frame Stepper | Delay | Frames to wait before hold-repeat starts. | Cheat |
| Frame Stepper | Every | Frames between repeated steps after the delay. | Cheat |
| Safe Mode | Freeze deaths | Restore the current save slot's death counter while Safe Mode is active. | None |
| Safe Mode | Freeze jumps | Restore the current save slot's jump counter while Safe Mode is active. | None |
| Safe Mode | Freeze best run | Restore the current save slot's best-run fields while Safe Mode is active. | None |
| Autosave | Interval | Seconds between automatic save attempts. | Goldberry/Hardlist clear |
| Autosave | Minimum delay | When Avoid gameplay is on, block automatic saves until this cooldown has passed after entering a level or completing a save. | Goldberry/Hardlist clear |
| Autosave | Level load | Autosave when a level starts or reloads. Room transitions do not trigger it. | Goldberry/Hardlist clear |
| Autosave | Spawn update | Autosave on spawn update. | Goldberry/Hardlist clear |
| Autosave | Respawn | Autosave on respawn. | Goldberry/Hardlist clear |
| Autosave | Pause | Autosave on pause. | Goldberry/Hardlist clear |
| Autosave | Avoid gameplay | Defer automatic saves while the minimum-delay cooldown is active. | Goldberry/Hardlist clear |
| Autosave | Save settings | Save Celeste settings with the active save file. | Goldberry/Hardlist clear |
| Autosave | Hide saving icon | Hide Celeste's save and load icons while this setting is on. | Goldberry/Hardlist clear |
| Autosave | Save now | Save the current file immediately through Akron's autosave path, even when Autosave is off or the minimum-delay cooldown is active. | Goldberry/Hardlist clear |
| Transition Speed | Speed | Adjust the next room-transition speed multiplier. Values below 1x are slower and values above 1x are faster. | Cheat |
