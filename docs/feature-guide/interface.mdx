The Interface tab controls the Akron overlay itself and the public `.akr` pack workflows.

| Option | Control | What it does | Classification |
|---|---|---|---|
| Theme | Selector | Select the Akron overlay color theme. | None |
| UI Scale | Number | Scale Akron overlay text and controls. | None |
| Opacity | Number | Set Akron overlay background opacity. | None |
| Export Setup | Action | Export the selected Whole, StartPos, Keybinds, Auto Kill, Auto Deafen, Recorder, Audio, or HUD setup scope as a `.akr` setup pack. | None |
| Import Setup | Action | Open a file browser to import a selected `.akr` setup pack using the selected setup scope. | None |
| Community Packs | Action | Search map-linked community `.akr` packs from the configured community pack index. | None |
| Upload Pack | Action | Submit the active map's StartPos, Auto Kill, or Auto Deafen setup through the moderated community catalog flow. | None |
| Pause While Open | Toggle | When enabled, opening the Akron menu stops gameplay updates until the menu closes. | None |
| Block Gameplay Input | Toggle | Keep gameplay input from reaching Madeline while the overlay is open. On by default. | None |
| Streamer Mode | Toggle | Replace full local filesystem paths with filenames. | None |
| Logging | Toggle | Write local Akron diagnostic logs to `Saves/AkronLogs`. | Goldberry/Hardlist clear |
| Search Autofocus | Toggle | Focus Akron search automatically when the overlay opens. | None |
| Search | Text input | Filter visible Akron rows by label or search alias. | None |

## Community packs browser

Clicking **Community Packs** opens a standalone browser window. Use it to search, refresh, and download community-curated `.akr` packs.

| Control | What it does | Classification |
|---|---|---|
| Index URL | The catalog JSON URL (default is `https://akron.micr.dev/catalog/index.json`). | Normal clear |
| Search | Filter the catalog by title, description, author, map URL, section label, or tag. | None |
| Category | Filter packs by setup scope: All, StartPos, Auto Kill, or Auto Deafen. | Normal clear |
| Refresh | Connect to the index URL and reload available packs. | Normal clear |
| Import Selected | Download and import the highlighted community setup pack. | Normal clear |

## Upload Pack

**Upload Pack** is the only public submission path for map-linked StartPos, Auto Kill, and Auto Deafen packs. Akron exports the selected section, captures at least one marked room, and sends the batch to private moderation storage. Staff approval publishes the pack to the catalog and creates its Discord showcase post.

Keybind, HUD, audio, and recorder packs are not map catalog entries. Post those exports in their matching Discord pack forums.
