The Interface tab controls the Akron overlay itself and the public `.akr` pack workflows.

| Option | Control | What it does | Classification |
|---|---|---|---|
| Theme | Selector | Select the Akron overlay color theme. | None |
| UI Scale | Number | Scale Akron overlay text and controls. | None |
| Opacity | Number | Set Akron overlay background opacity. | None |
| Export Setup | Action | Export the selected Whole, StartPos, Keybinds, Auto Kill, Auto Deafen, Recorder, Audio, or HUD setup scope as a `.akr` setup pack. | None |
| Import Setup | Action | Open a file browser to import a selected `.akr` setup pack using the selected setup scope. | None |
| Pause While Open | Toggle | When enabled, opening the Akron menu stops gameplay updates until the menu closes. | None |
| Block Gameplay Input | Toggle | Keep gameplay input from reaching Madeline while the overlay is open. On by default. | None |
| Menu Mouse | Toggle | Hold the Menu Mouse key (`Left Alt` by default) to use the mouse in Celeste menus: the pause menu, options and mod options, the main menu, file select, chapter select, the chapter panel, and the journal. Hover selects a row, left click confirms it or steps the value under the cursor, right click goes back, and the wheel scrolls long lists. The list stays still while you hold the key and recenters on the selection when you let go. In chapter select and the chapter panel, click once to select and again to open. On Linux desktops that move windows with Alt+drag, such as Cinnamon, the desktop takes Alt+clicks before the game does; bind another key in the popup or change the desktop's window-move key. On by default. | None |
| Streamer Mode | Toggle | Replace full local filesystem paths with filenames. | None |
| Logging | Toggle | Write local Akron diagnostic logs to `Saves/AkronLogs`. | Goldberry/Hardlist clear |
| Save diagnostics | Action | Save a report with recent logs, mod versions and system details to the AkronDiagnostics folder inside the Celeste install. | None |
| Search Autofocus | Toggle | Focus Akron search automatically when the overlay opens. | None |
| Search | Text input | Filter visible Akron rows by label or search alias. Matching panels open temporarily with space for their visible rows; clearing Search restores their saved collapsed state. | None |
