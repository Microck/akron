---
title: Level
description: Level-scoped tools for automation, freezing, proof helpers, visual suppression, and hitbox display.
---

The Level tab focuses on the current level scene. Several rows are useful for routing and review, but state-changing rows can mark the attempt as Cheat.

| Option | Control | What it does | Classification |
|---|---|---|---|
| Core Mode | Action | Apply the configured Hot or Cold Core Mode override, or cycle directly between Hot and Cold. | Cheat |
| Freeze Gameplay | Action | Freeze gameplay updates until toggled off or advanced by the frame stepper. | Cheat |
| Confirm Restart | Toggle | Require a confirmation prompt before restarting the current room attempt. | Goldberry/Hardlist clear |
| Confirm Full Reset | Toggle | Require a confirmation prompt before fully reloading the current chapter. | Goldberry/Hardlist clear |
| Skip Intro | Toggle | Hold confirm on repeated B-side intro title screens to enter the map. | Normal clear |
| Skip Postcards | Toggle | Hold confirm on level-entry postcards to jump straight into the map. | Normal clear |
| Auto Kill | Toggle | Automatically kill the player after a configured map-time threshold or inside selected regions. | Cheat |
| Respawn Time | Toggle | Open respawn timing controls, including whether speedhack affects the delay. | Normal clear |
| Pause Timer | Toggle | Delay resumed gameplay after unpausing and show a center countdown. | Cheat |
| Pause Tracker | Toggle | Record pause count, rapid pauses, and paused time. | Goldberry/Hardlist clear |
| Lag Pauser | Toggle | Pause after a detected frame-time spike. | Goldberry/Hardlist clear |
| Freeze Timer While Paused | Toggle | Halt level and journal timer accumulation while paused. | Cheat |
| Hide Pause Menu | Toggle | Hide Celeste's pause menu while the game remains paused. | Normal clear |
| Auto Deafen | Toggle | Press the configured Discord Toggle Deafen hotkey after entering a selected region until death or reset. | Normal clear |
| Deload Spinners | Action | Simulate spinner deload timing with the configured delay. | Cheat |
| Show Hitboxes | Toggle | Open live hitbox controls for collision boxes, filters, colors, opacity, thickness, and style. | Cheat |
| Fix Hitbox Pixels | Toggle | Render circular hitboxes as sampled collision pixels instead of a smooth approximate outline. | Normal clear |
| Show Hitbox Trail | Toggle | Draw recent player collision boxes behind Madeline. | Cheat |
| Show Hitboxes On Death | Toggle | Show the death-object hitbox after dying without enabling live hitboxes. | Normal clear |
| Show Triggers | Toggle | Draw invisible Celeste trigger regions without turning on all hitboxes. | Cheat |
| Refill Clarity | Toggle | Highlight already-visible one-use refills with a configurable outline. | Normal clear |
| Screenshake | Toggle | Override native Celeste screenshake. Intensity 0 disables shake. | Goldberry/Hardlist clear |
| Light Level | Toggle | Adjust light presentation for the current level. | Normal clear |
| Bloom Level | Toggle | Adjust bloom presentation for the current level. | Normal clear |
| Screen Tint | Toggle | Apply a configurable screen tint. | Normal clear |
| Reduced Visual Noise | Toggle | Apply Akron's reduced visual-noise presentation settings. | Normal clear |
| No Particles | Toggle | Suppress particle presentation. | Normal clear |
| No Glitch | Toggle | Suppress glitch-style visual effects. | Normal clear |
| No Anxiety | Toggle | Suppress anxiety-style visual effects. | Normal clear |
| No Distortion | Toggle | Suppress distortion-style visual effects. | Normal clear |
| Hide Snow | Toggle | Hide snow presentation. | Normal clear |
| Hide Wind Snow | Toggle | Hide wind-snow presentation. | Normal clear |
| Hide Waterfalls | Toggle | Hide waterfall presentation. | Normal clear |
| Hide Tentacles | Toggle | Hide tentacle presentation. | Normal clear |
| Disable Playback | Toggle | Hide map-placed playback tutorial ghosts and suppress their movement, audio, and trails during gameplay. | Normal clear |
| Hide Heat Distortion | Toggle | Hide heat-distortion presentation. | Normal clear |
| No Death Wipe | Toggle | Suppress black screen wipes while preserving completion callbacks when configured. | Normal clear |
| No Freeze Frames | Toggle | Suppress native hitstop/freeze-frame pauses. This changes gameplay timing. | Cheat |

<Note>
  Auto Deafen hotkey injection is available on Windows and Linux, not macOS. On Linux, it needs an X display with XTest support or an available `xdotool` fallback, including `flatpak-spawn` when applicable.
</Note>
