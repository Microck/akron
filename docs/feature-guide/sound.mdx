---
title: Sound
description: Audio routing, low-volume handling, speed, pitch, and per-sound volume overrides.
---

The Sound tab changes audio presentation. Sound overrides are collapsed under five expandable groups: **Player**, **Objects**, **Entities**, **Ambience**, and **UI**. Expand a group to show its per-sound rows; search also reveals matching rows while a group is collapsed.

| Option | Control | What it does | Classification |
|---|---|---|---|
| Audio Splitter | Toggle | Route music and sound effects to configured output devices. | None |
| Allow Low Volume | Toggle | Force music and SFX to configured low-volume values while enabled. | Normal clear |
| Audio Speed | Toggle | Control whether audio follows timescale, stays normal, or uses an independent speed multiplier. | Normal clear |
| Pitch Shift | Toggle | Control whether active music/ambience pitch is preserved, follows audio speed, or uses an independent multiplier. | Normal clear |

## Sound override groups

Each per-sound row is a **Normal clear** toggle that enables or disables the matching volume override.

| Expandable group | Per-sound rows |
|---|---|
| Player | Death, Respawn, Golden Death |
| Objects | Broken Window, Conveyor, Core Block, Dream Block, Drum Swap Block, Kevin Block, Move Block, Spring, Touch Switch Complete, Zip Mover |
| Entities | Fireball, Lava Barrier, Lightning Strike, Oshiro Boss, Seeker |
| Ambience | Bird Squawk, Lightning Ambience, Farewell Wind, Ridge Wind |
| UI | Dialogue, Heart Collect, Item Crystal Death, Pico-8 Flag |

## Option menus

Rows with a triangle expose the controls listed below.

| Option | Menu control | What it changes | Classification |
|---|---|---|---|
| Audio Splitter | Reload Devices | Refresh FMOD output devices visible to Celeste. | None |
| Audio Splitter | Main | Choose the output device for the main audio route. | None |
| Audio Splitter | Music | Choose the output device for the music audio route. | None |
| Audio Splitter | SFX | Choose the output device for the sound effects audio route. | None |
| Allow Low Volume | Music | Set forced low music volume. | Normal clear |
| Allow Low Volume | SFX | Set forced low SFX volume. | Normal clear |
| Audio Speed | Policy: Normal/SyncTimescale/Independent | Choose normal speed, Akron timescale sync, or an independent audio speed. | Normal clear |
| Audio Speed | Speed | Set the independent audio speed multiplier. | Normal clear |
| Pitch Shift | Policy: Preserve/FollowSpeed/Independent | Choose normal pitch, pitch following audio speed, or an independent pitch. | Normal clear |
| Pitch Shift | Pitch | Set the independent pitch multiplier. | Normal clear |
| [Sound event] | Volume | Set volume percentage for the overridden sound (0% to 200%). | Normal clear |
