---
title: Keybinds
description: Review Akron overlay bindings and the built-in action bindings exposed by the current build.
---

The Keybinds tab always shows **In-game only** and lists an action only while that action has a visible binding. Select a keybind row to replace its binding, or use **X** to clear it. **Open Menu** resets to its default instead of becoming unbound. Bind an omitted action from its source row or submenu to make it appear here.

| Option | Control | What it does | Classification |
|---|---|---|---|
| In-game only | Toggle | Restrict Akron menu bindings so they only fire while a level is active. | None |
| Open Menu | Keybind | Show the binding used to open or close the Akron overlay. | None |
| Retry | Keybind | Restart the current room attempt by forcing a death and respawn. | Normal clear |
| Reload Room | Keybind | Restart the current room. | Cheat |
| Reload Chapter | Keybind | Restart the current chapter through Celeste's loader. | Normal clear |
| Speedrun Tool Capture State | Keybind | Save the current state into the active Speedrun Tool slot from 1-9. This is Speedrun Tool's savestate, not an Akron StartPos. | Cheat |
| Speedrun Tool Restore State | Keybind | Load the active Speedrun Tool slot from 1-9, or report why it cannot be loaded. | Cheat |
| Show Hitboxes | Keybind | Toggle live hitbox rendering on or off. | Cheat |
| Freeze Gameplay | Keybind | Freeze gameplay updates until toggled off or advanced by the frame stepper. | Cheat |
| Cursor Zoom | Keybind | Set the input used by Cursor Zoom. Hold or press it according to the selected activation mode, then use the mouse wheel to change cursor-centered zoom. | Cheat |
| Cursor Tools | Keybind | Set the hold input that temporarily enables the selected Cursor Tools actions. Left click uses either Click Teleport or Entity Inspector. | Cheat |
| StartPos Set | Keybind | Capture the current position and room state into the active persistent StartPos slot. | Cheat |
| StartPos Load | Keybind | Load the active persistent StartPos slot. | Cheat |
| StartPos Clear | Keybind | Clear the active persistent StartPos slot. | Cheat |
| StartPos Previous | Keybind | Move to the previous saved persistent StartPos in chapter order. | Cheat |
| StartPos Next | Keybind | Move to the next saved persistent StartPos in chapter order. | Cheat |
| StartPos Slot 1-9 | Keybind | Load a fixed persistent StartPos slot from 1-9. | Cheat |
