Akron HUD tools display local state and review information. Each surface has a clear policy: **Goldberry/Hardlist clear**, **Normal clear**, or **Cheat**. Cheat surfaces expose precise resources or hidden information.

## HUD surfaces

| Surface | Use it for | Classification |
|---|---|---|
| Room | Show passive room information. | Normal clear |
| Input History > Current inputs | Show current local inputs as a text chord. | Goldberry/Hardlist clear |
| Control Display | Show a visual overlay of pressed keys or buttons. | Goldberry/Hardlist clear |
| Input History | Review recent input state in a scrolling panel. | Goldberry/Hardlist clear |
| Inputs per second | Monitor your current input press rate. | Normal clear |
| Room Timer | Show timing information for the current room. | Normal clear |
| Room Stat Tracker | Show room name, deaths, timer, berry count, and alive time. | Normal clear |
| Death Stats | Show death counters. | Goldberry/Hardlist clear for the base feature |
| Attempts | Show the current attempt number. | Goldberry/Hardlist clear |
| Status | Show presentation overlays and attempt status. | Normal clear |
| Custom HUD labels | Show configured labels with templates that can expose exact player or resource state. | Cheat |
| Stamina, dash, speed resources | Show exact resource state. | Cheat |

## Configure HUD output

<Steps>
  <Step title="Check the visible status">
    Read the row badge to learn how Akron classifies the display. Check the attempt-status chip for the strictest classification Akron has recorded during the current attempt.
  </Step>
  <Step title="Enable one surface at a time">
    Turn on **Visible** in the Labels tab, then enable one display row. Open its popup to configure labels, colors, placement, or display limits.
  </Step>
  <Step title="Check suboptions">
    Read any suboption policy badges. The Death Stats PB loss prompt and capture timer-freeze options carry a different policy from their parent rows.
  </Step>
  <Step title="Test in a room">
    Close the overlay and confirm the widget appears where expected without covering gameplay-critical information.
  </Step>
</Steps>

## Create a custom label

<Steps>
  <Step title="Open the Labels tab">
    Open the Akron overlay, go to **Labels**, and enable **Visible**.
  </Step>
  <Step title="Add a row">
    Choose **+ Custom**. Akron creates a new custom label row, enables custom HUD labels, and selects the new row.
  </Step>
  <Step title="Open the row options">
    Open the new custom label row to edit its name, text, placement, style, and event behavior.
  </Step>
  <Step title="Write the template">
    Set **Text** to plain text plus variables in braces, such as `Room {room_time}` or `{overlays} / {status}`.
  </Step>
  <Step title="Place and test it">
    Choose an anchor, tune the offset or absolute position, close the overlay, and verify the label is readable in a room. Custom labels render only while both **Visible** and the custom label are enabled.
  </Step>
</Steps>

See [Custom labels](/feature-guide/custom-labels) for template variables, expressions, events, placement, and shareable label packs.

## Input tools

Use **Input History > Current inputs** to see your current inputs as a text chord. Use **Input History** to review recent inputs after movement, death, or a routed attempt. Enable **Control Display** for a visual overlay of pressed keys or buttons. Check **Inputs per second** to monitor your press rate.

Input displays show local inputs without changing gameplay. Anything that synthesizes or redirects inputs sets the attempt status to Cheat.

## Room stats and labels

The **Room Stat Tracker** shows room name, deaths, timer, berry count, and alive time in the label HUD. Its freeze behavior is a tracker suboption with its own policy badge - check it separately from the base label.

Use [Custom labels](/feature-guide/custom-labels) when you want to build your own HUD text from Akron variables, event triggers, and label-specific styling.

## Streamer Mode

**Streamer Mode** replaces local filesystem paths with filenames or final folder names in Akron-owned UI and proof output. In-game data remains visible.
