# Security checks for a GitHub release

If a release credential was exposed, rotate it, review access to the GitHub release environments, and inspect recent tag and workflow changes. Verify the trusted Celeste reference archive against its recorded SHA-256 digest.

Review the [release permissions](pre-release-security-checklist.md) and follow the [release runbook](release-runbook.md). Test installation from the published ZIP and import a local setup pack before announcing the release.
