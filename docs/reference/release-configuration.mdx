---
title: Release configuration
description: GitHub settings for building and publishing Akron.
---

The `release-build` GitHub environment provides the reference bundle for compiling against Celeste and Everest. Set the secret `AKRON_CELESTE_REFS_URL` to the archive's GitHub release asset API URL and set the variable `AKRON_CELESTE_REFS_SHA256` to its SHA-256 digest. Set `AKRON_CELESTE_REFS_TOKEN` only if the build needs read access to a separate private repository. The verifier checks the digest before extracting the DLLs.

The `release` environment publishes the versioned ZIP, checksum, dependency list, and software bill of materials to GitHub Releases. GitHub Actions supplies the token for publishing and attestation.
